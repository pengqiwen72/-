# 仓储与库存管理规范

## 库存口径

- 可用量 = 在库量 − 预留量。已分配给出库单、待出库的库存属于预留量，
  不能被新的申请占用；
- 安全库存按「物料 × 仓库」维护，低于安全库存线的仓库在库存查询里单独提示；
- 可支撑天数 = 全仓在库量 ÷ 近 30 天日均出库量。可支撑天数低于供应周期的
  物料需要提前补货。

## 收货与验收

到货后核对采购订单，登记实收数量与不良数量。不良率 = 不良数量 ÷ 实收数量：

- 不良率不超过 2% 的，按常规流程验收入库，当日完成；
- 不良率超过 2% 的，冻结入库并转质检主管复核，复核结论应在 4 小时内给出，
  处置方式包括：让步接收（整批放行并记录质量档案）、退货（整批拒收退回）、
  换货（退回不良批次，由供应商补发）。

实收数量与不良数量是登记环节写下的事实，复核环节只能确定处置方式，不能
修改已经登记的实收数量与不良数量。

## 调拨

各仓库存不均衡时，用调拨代替重复采购：从可用量高于安全库存线的余量仓，
调往低于安全库存线的缺口仓。调拨量按缺口量确定；调出仓余量不足以一次
补齐缺口的，按余量上限调拨，且调出后调出仓的可用量仍不得低于其安全库存线。
调拨由仓储主管确认后执行。

## 盘点

循环盘点按 ABC 分类安排：A 类物料每月盘点一次，B 类每季度一次，C 类每半年
一次。盘盈盘亏需要说明原因并留档，差异金额较大的报财务复核。
