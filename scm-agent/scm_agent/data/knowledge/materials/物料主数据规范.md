# 物料主数据规范

## 编码规则

物料编码为「M + 6 位数字」（如 M100023），一料一码，规格不同即为不同编码；
供应商编码为「S + 3 位数字」（如 S001）；仓库编码为「WH + 2 位数字」（如 WH01）。
编码一经启用不再复用，物料停用后编码保留为历史编码，不重新分配。

## 名称与规格

物料名称由「通用名 + 规格段」组成，如「冷轧钢板 1.2mm」。厚度、牌号、直径等
规格参数写在规格段里。规格不同但可以互换使用的物料，通过替代料关系维护，
不靠名称近似来猜。

## 计量单位

常用计量单位为 公斤（kg）、支、件、米、卷。同一物料在所有单据上使用同一
计量单位，单位以物料主数据为准。吨与公斤的换算统一在主数据层完成，下游
申请与订单只使用主数据单位。

## 替代料关系

替代料关系是一对多的互替清单，由工艺部门确认后录入主数据。车间报缺料、
仓库报断料时，先在本物料的替代料清单里找有货的物料，而不是直接发起新的
采购申请。替代料启用前需要确认规格差异是否影响产线使用，差异较大的要经
工艺部门逐单确认。

## 安全库存

安全库存按「物料 × 仓库」两级维护。安全库存线由计划部门根据近 30 天出库量
与供应周期测算；季节性或试产阶段的物料可以临时下调，但需要计划部门留档。
可用量低于安全库存线的仓库要触发补货或调拨评估。

## 变更管理

物料名称、规格、单位、替代料关系的变更走主数据变更单，由主数据管理员审核
后生效。已经提交的采购申请与订单不因主数据变更而自动改写，需要变更的按
单据变更流程处理。
